1. 배경과 문제
학생들은 이미 순공 타이머·플래너·스터디 캘린더를 따로 쓴다. 기존 앱의 문제는 세 가지다.
측정이 자기 신고다. 버튼을 누른 시간이 곧 공부 시간이 된다. 자리를 비워도 타이머는 돈다.
계획과 기록이 분리돼 있다. 플래너에 적은 할 일과 타이머의 시간이 서로를 모른다. 학생이 두 번 입력한다.
평가가 압박이 된다. 점수·등급·랭킹·끊긴 스트릭이 죄책감을 만들고, 그 결과 앱을 지운다.
2. 목표
목표 성공 지표 (출시 후 8주) 
G1 순공시간이 자동으로, 정확하게 쌓인다 착석 감지 세션 비율 ≥ 70% · 잘못 감지 정정 ≤ 세션당 0.3회 · 정정 후 감도 자동 조정으로 4주차 정정율 절반 
G2 계획한 할 일과 측정된 시간이 한 곳에서 만난다 세션 중 할 일 연결 비율 ≥ 60% · 주간 플래너 등록 ≥ 5건/사용자 
G3 평가 없이도 계속 돌아온다 D30 리텐션 ≥ 35% · 주 4일 이상 사용 비율 ≥ 40% · 스트릭 끊김 후 7일 내 복귀 ≥ 50% 
G4 AI는 성취 축에서만 값을 만든다 프리미엄 전환 ≥ 6% · 판독 후 사용자 확정 없이 저장된 건 0 · 오답 재풀이 완료율 ≥ 40% 
3. 사용자와 원칙
사용자는 학생 한 명이다. 선생님·학부모 계정은 존재하지 않고, 데이터는 학생의 기기에만 있다. 이 전제에서 나오는 제품 원칙:
순공시간이 유일한 대표 지표. 집중도 점수·등급·레벨·타인 비교·리포트 발송을 만들지 않는다.
앱은 평가하지 않는다. "부족합니다", "잘했어요" 같은 문장 금지. 사실(시간·개수·날짜)만 말한다.
결정은 학생이 한다. 목표 시간·계획·복습 여부는 학생 입력. 시스템은 기록 기반 기본값과 근거만 제공한다.
카메라는 얼굴을 보지 않는다. 착석 여부만 온디바이스로 판정하고 영상은 저장하지 않는다.
AI는 성취 축에만. 채점 표시 판독 → 오답 누적 → 복습 큐. 시간 축(측정·계획)은 AI가 개입하지 않는다.
4.3b 판독 플로우 상세 (v1.3 확정 · AI 완성 시 그대로 연결)
우선 항목 요구사항 화면 
P0 사진 확인 · 요청 촬영/앨범 → 사진 확인 (현재 사진 · 썸네일 이동 · 추가 · 삭제 · 재촬영) → 과목·범위 확인 → 판독 요청. 플래너에서 진입하면 할 일의 과목·범위를 이어받는다. 사진 0장 또는 범위 비어 있음은 요청 불가 안내. 취소는 출발 화면(플래너/오답)으로 복귀하고 선택은 버린다. 요청 전(선택 중)과 요청 후(판독 중)를 화면으로 구분한다. A1b 
P0 진입 조건 순서 판독 요청 클릭 시 잔여 횟수 → 인터넷 연결 순서로 검사. 없음 → 소진 시트(요금제 / 닫기), 연결 없음 → 오프라인(다시 시도=연결 재확인 / 사진 두고 나중에). 사진·입력은 어느 경우에도 유지. A1b·F7 
P0 전송 상태 전송 중(진행 표시 · 전송 취소) / 실패(사진·입력 유지 · 다시 보내기 · 닫기). 재시도는 같은 요청 ID로 보내 중복 저장이 생기지 않는다. 진행 중에는 요청 버튼을 잠근다. A1c 
P0 판독 중 · 이탈 판독 중 화면: 처리 중 / 오래 걸림 안내(닫아도 요청 유지) / 실패(다시 찍기 → 촬영, 취소 → 사진 확인, 횟수 미차감). 닫고 나중에 확인 은 요청을 유지하고 홈으로, 요청 취소 는 확인창 후 요청을 없애고 사진 확인으로. 두 동작은 다르다. A2 
P0 미저장 결과 재진입 처리가 끝났지만 저장하지 않은 결과는 홈 상단 확인 대기 카드 (1건)로 표시하고 탭하면 결과 확인으로 재진입. 진행 중이면 같은 카드가 "판독 진행 중"으로 표시되어 판독 중 화면으로 복귀. 저장 전 결과는 오답·복습에 반영되지 않는다. 01·A3 
P0 결과 확인 페이지 탭(N페이지 · 확인 필요 점) · 원본 확대(페이지 이동, 확인 필요 테두리) · 확인 필요 문항으로 이동 (해당 페이지 전환 + 강조) · 문항 탭으로 마크 수정 · 확인 미완료(저장 불가)와 저장 가능 상태 구분 · 저장 중 / 성공 → 오답 상세 / 실패(마크 유지 · 다시 저장). A3 
P0 오답 0개 틀림·애매·확인 필요가 모두 0이면 "틀린 문항이 없습니다" 카드. 저장하면 판독 이력에만 남고 복습 큐에는 추가되지 않으며 오답 누적으로 복귀. 처리 실패·데이터 없음과 다른 상태이며 평가 문구는 넣지 않는다. A3 
P0 저장 전 이탈 뒤로/닫기 → 계속 확인하기 / 나중에 확인(홈 카드에 두기) / 결과 버리기 3분기. 버리기는 판독 결과만 지우고 사진은 보관 목록에 남는다. 앱 내 임시 보관을 넘어선 "임시 저장" 기능은 두지 않는다. A3 
P0 저장 결과 관리 오답 상세 › 판독 결과 카드: 결과 열기·마크 수정 (변경 저장 / 변경 취소 → 확인 후 원본 유지) · 같은 범위 다시 찍기 (이미 판독한 범위 안내 → 새 회차 / 기존 결과 수정) · 이 판독 결과 삭제 (영향 범위 명시: 오답 N · 복습 큐 N · 재풀이 N 삭제 / 사진·세션은 남음 → 오답 누적으로 복귀). 결과 삭제 ≠ 사진 삭제 ≠ 재풀이 기록 삭제. A6·A3
