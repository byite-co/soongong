## 세그먼트·저장 규칙 (D23)

`MeasureController`는 `SessionClock`의 벽시계 시작점 + 단조 경과를 쓴다. 엔진 `sinceStart`는 매번 start 직전의 단조 시각에 더하고 `receivedAt`은 계산에 사용하지 않는다. 이전 실행 세대의 샘플은 버린다. 수동=manual, 일시정지·백그라운드·카메라 끊김=paused, 확인된 이탈=away다. 60/75/90초 임계 확인 시 마지막 착석으로 최대 90초 소급한다. 열린 구간은 화면에서 계산하고 상태 전환 시 닫는다.

시작 시 active 행과 첫 스냅샷을 먼저 저장한다. 15초마다 단일 `session_snapshot`을 덮어쓰고 상태 전환 시에도 체크포인트를 남긴다. 종료 후 아직 저장하지 않은 행은 ended_at 없이 interrupted로 남겨 복구 대상이 된다. 최종 저장은 같은 세션 ID를 갱신하고 닫힌 구간·캐시 순공을 쓰며, 해당 세션의 스냅샷만 삭제한다. 스키마와 `core/contracts/**` 시그니처 변경은 없다.

## 복구

| 스냅샷의 열린 구간 | 마지막 스냅샷 정산 |
|---|---|
| seated, 이탈 후보 없음 | saved_at까지 착석 |
| seated, 이탈 후보 있음 | last_seated_at까지 착석, 이후 saved_at까지 away |
| manual | saved_at까지 순공 |
| away / paused | saved_at까지 닫되 순공 제외 |
| 스냅샷 없음 | started_at에 종료, 0초 |

스냅샷 이후 시간은 추가하지 않는다. “이어서”는 새 단조 기준점을 만들고 복구 시각과 재개 사이를 paused로 남긴 뒤 같은 세션에 새 구간을 연다. 복구한 세션은 이어서 측정한 뒤 저장해도 interrupted다. “버리기”는 세션·구간·정정 기록과 해당 스냅샷을 삭제한다. 스냅샷 저장이 정상 동작할 때 비정상 종료로 잃을 수 있는 최신 측정은 최대 15초이며, 체크포인트 실패는 화면에서 재시도 가능하다.
