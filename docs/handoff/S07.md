## 다음 세션이 알아야 할 것
- **S08(타임테이블·통계)**: 월별 집계는 `ref.watch(plannerMonthProvider('yyyy-MM'))` → `MonthAggregate.days[date].seatedSeconds / items / recurrences`, `bands`, `sessionsByItem`. 일별 순공 규칙이 홈·측정과 같다. 반복 편집 위젯은 `RecurrenceEditor` + `RecurrenceFields`(`PlannerDraft`와 무관), 저장은 `PlannerController.save(PlannerDraft.fromRecurrence(...), ExistingRecurrence(id))` 또는 `PlannerRepository.updateRecurrence`. 삭제 5초 되돌리기는 `PlannerController.delete(ExistingRecurrence(id))` → `showUndoToast(onUndo: pending.undo)`.
- **S09(설정)**: 주 시작 요일은 `settings.week_start`(격자·날짜 선택기·반복 편집기 모두 `plannerWeekStartProvider`).
- **S10(판독)**: `/reading/capture?from=planner&itemId=` 수신 → `PlannerRepository.getItem(itemId)` → `readingRangeText`(범위 없으면 제목, D27) · `subjectId`. 무료 가드는 S10/S12.
- **S12(요금제)**: `plannerEntitledProvider`가 `BillingGateway.entitlement`만 읽는다. 페이월 라우트가 생기면 `PlannerScreen._openSheet`의 `onOpenPaywall`(`/settings`)을 교체.
- **S14(통합)**: 시트의 레이아웃은 `ConstrainedBox(maxHeight 0.8)` + `SingleChildScrollView`(viewInsets 패딩). 긴 시트(반복 + 달력)는 스크롤. 프로토타입과 1:1이 아닌 간격은 S14 정리.
- 테스트 키: `PlannerKeys`(화면) · `PlannerGridKeys`(격자) · `PlannerSheetKeys`(시트). 위젯 테스트는 `AppHarness(localOnly)`로 탭 → 플래너.
