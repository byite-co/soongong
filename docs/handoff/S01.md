## 안 한 일 · 미확인

- **GitHub Actions 워크플로가 등록되지 않았다**: push 후 GitHub API 가 워크플로 0개를 반환하고 `workflow_dispatch` 가 404 였다(레포/조직에서 Actions 비활성으로 추정). Settings → Actions → General 에서 허용한 뒤 `analyze-test` · `build-android` 를 수동 실행해 "CI 2개 그린" 을 확인해야 한다.
- **`flutter build apk --flavor dev --debug` 는 이 환경(클라우드 컨테이너)에서 실행하지 못했다** — Android SDK 배포 호스트(dl.google.com)가 차단됨. Gradle 설정은 표준 DSL 이며, `build-android.yml` 워크플로를 수동 실행해 확인해야 한다(완료 기준 중 이 항목은 CI 로 검증).
- iOS 프로젝트 변경(pbxproj·xcconfig·스킴)은 macOS/Xcode 없이 작성 → S15 iOS 워크플로에서 검증. CocoaPods 가 개입하면 `Pods-Runner.<config>-<flavor>.xcconfig` include 는 이미 들어 있다.
- 기능 화면 없음(지시문대로). Supabase 초기화·RevenueCat 구성·drift DB 초기화는 각 세션(S03·S12·S02).
