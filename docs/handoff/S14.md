## 첫 CI에서 확인한 SQL 진단 (22a89e0, 2026-10-12)

pgTAP 352/352 통과. plpgsql_check: error 2, security 2, warning 8, warning extra 1, performance 35(총 48).
- error 2는 `sync_pull(integer,bigint,integer)` 36/37행의 `rec` 미할당 진단. `0003_sync_rpc.sql`은 `FOR rec IN EXECUTE ... USING` 결과를 loop 안에서 읽는다. 동적 결과형을 정적으로 추론하지 못한 항목으로 판단하며, 정확한 routine/line/SQLSTATE/message를 baseline에 남긴다. 새 error/checker_exception은 CI 실패. pgTAP의 실제 동기화 동작/인가 검증을 유지한다.
- security 2는 sync_pull의 동적 SQL과 sync_write_row의 text 열 목록. 소스는 식별자 `%I`/`quote_ident`, literal `%L`, 값 `USING`을 사용하며 sync_write_row의 외부 EXECUTE도 revoke되어 있다. 이 진단만으로 injection 결함이라고 확정하지 않는다.
- 나머지 형변환·volatility·unused 경고는 출력에 보존. 이 PR에서 운영 migration을 임의 수정하지 않았다.
- 첫 Deno CI에서 Zod 길이 정책과 UTF-16 `String.length` 차이를 emoji 회귀가 발견했다. 명시적 refine으로 기존 code-unit 제한을 보존하고 한글/emoji/결합문자/단독 surrogate 생성 케이스를 추가했다.
