## 다음 세션이 알아야 할 것
- 인증 초기화 실패 시 평문으로 후퇴하지 않는다. Android/iOS 실제 보안 저장소·OAuth/비밀번호 복구 흐름은 기기 검증 필요.
- 좁은 시간표에서 겹침 열이 많을 때 탭 영역이 작아지는 기존 주간 격자 한계는 남는다.
- plpgsql_check 출력은 정적 진단 baseline이며 성공 exit를 모든 SQL 무결성 확인으로 해석하지 않는다.
- export는 계정별 조회·인코딩 분리이며 수치 성능 개선을 아직 측정하지 않았다.
- 새 서버 패키지 버전/무결성은 deno.json/lock에 고정. 운영 SQL/Edge 배포 없음.
